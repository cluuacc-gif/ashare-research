# A股云端采集入口验收包

本包将真实行情请求移至独立 GitHub Actions runner。ChatGPT Work 的网络设置保持不动。当前状态：2026-09-11 云端真实入口验收已通过；已取得沪深北完整分页的当前市场清单，并为三个市场各验证至少250根真实未复权OHLCV。全市场250日回填、正式状态核验和概率模型仍未完成，因此正式数据状态仍为 `DATA NOT READY`。

## 如何部署本次验收

目标必须是用户指定的独立私有仓库。当前已连接GitHub，但可见仓库均为其他项目；不能擅自占用。现有GitHub工具未提供新建仓库动作。

用户在GitHub创建 `ashare-research` 私有仓库，初始化README，并让当前GitHub连接可访问。把链接交给执行者，由执行者将本目录内容部署至仓库根目录。本包不含任何生产数据库或个人预测记录。

文件推送到main后只启动一次真实数据验收；也支持Actions页面手动Run workflow。无需平板执行Python或保持平板常亮。使用GitHub托管运行资源，额度与计费由账户设置决定；未验证免费额度，不自动开通付费服务。

## 验收究竟验证什么

1. 从上交所主板、科创板、深交所、北交所实际读取当前证券名单；保留AKShare标准化响应，不冒充原始HTTP字节。
2. 按代码机械选择三个市场各一只有足够上市历史的证券。它们只是数据接口测试对象，不是选股名单。
3. 请求至少250根真实未复权OHLCV。东方财富失败时尝试腾讯；成交额缺失单列。遵守权限拒绝，不绕过401/403。
4. 原始历史响应、标准化行、URL、抓取时间、哈希、实际行情日期和错误一起保存到运行产物。没有来源披露时间的字段保留null。
5. 不写行情生产库，不写预测库，不生成任何股票概率。无合成或随机行情。

`CLOUD_SOURCE_PROBE_PASS`仅表示至少一个真实供应商的全市场当前清单完整分页通过数量及字段校验，并且三市场各一个历史接口测试成功。官方名单接口的成功与失败单独记录，供应商清单不冒充官方清单。全A历史覆盖仍然未完成，正式数据状态仍为`DATA NOT READY`。

## 通过真实验收后的接续部署

仓库确定、云端真实行情验收完成后才接续：

- 恢复同一行情库及全部快照/证据，核对原Library ID `libfile_d756624099288191b2687f1948b17c94`和最新版本哈希。云端工作副本必须保留同一谱系；不得拿旧压缩包覆盖当前数据。
- 使用附带原采集器 `collector.py` 执行全主表、首次250日回填和质量检查。每次退出保留断点，不把失败任务的旧数据当最新成功数据。
- 补齐官方交易日历、状态、限价与必要证据；不能靠普通工作日推断开市。原程序未实现自动公告抓取与完整因子引擎，本验收包未声称补齐。
- 启用北京时间18:00采集。若用GitHub UTC cron，对应 `0 10 * * 1-5`，触发后仍查交易所日历。GitHub调度可能延迟，不能保证18:00整点或限定完成时间；失败重试和次晨截止控制需在部署阶段接入。
- 跨日交接必须下载运行产物，校验日期/哈希/覆盖率，再替换同一行情库版本；成功持久保存后才更新原交接文件 `libfile_d5f3ecbb7d448191adaa8f1cbf66e977`。GitHub产物默认有保留期限，不是永久数据库备份。
- 次日09:00读已验收的T日数据并补充隔夜信息，禁止重新全量回填；需区分DATA READY与模型已验证。模型未训练时不得输出伪精确概率。

以上日常调度与自动交接尚未部署；本包只有可审查的云端入口验收工作流和原采集器。不能把本说明当作已完成的系统。

原预测库 `libfile_439779fd184481919947d99c2ec8a9c0` 始终保留身份和历史，不会上传至此仓库。
